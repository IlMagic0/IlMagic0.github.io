Architettura Backend & Microservizi Java 21 • Spring Cloud • Python AI • Blender

Pipeline Distribuita a Microservizi Java 21 • Spring Boot 3.5 • Netflix Eureka

Pipeline Automatizzata di Computer Vision & Rendering 3D

Architettura distribuita composta da 8 microservizi Spring Boot orchestrati tramite Netflix Eureka Service Discovery e Load Balancing lato client. Il sistema automatizza l'elaborazione di immagini fotografiche di veicoli fino al rendering 3D fotorealistico finale:

  • Orchestrazione & Cloud Storage: Un servizio orchestratore coordina le chiamate REST multipart tra i nodi e sincronizza i file con Amazon S3 tramite un microservizio dedicato.
  • Computer Vision & Segmentazione AI: Integrazione di worker Python per la rimozione dello sfondo (rembg), segmentazione semantica dei finestrini tramite modello YOLOv8 e calcolo dell'inclinazione del veicolo con OpenCV.
  • Rendering 3D Dinamico Headless: Instradamento condizionale verso due nodi di rendering (piano o inclinato) che avviano istanze headless di Blender 4.3 (Cycles GPU/CUDA) per generare ombre, maschere alpha e il render 3D finale.
