Backend & Microservices Architecture Java 21 • Spring Cloud • Python AI • Blender

Distributed Microservices Pipeline Java 21 • Spring Boot 3.5 • Netflix Eureka

Automated 3D Vehicle Rendering & Computer Vision Pipeline

Architettura distribuita composta da 8 microservizi Spring Boot orchestrati tramite Netflix Eureka Service Discovery e Load Balancing lato client. Il sistema automatizza il processing di immagini fotografiche di veicoli fino al rendering 3D fotorealistico finale:

  • Orchestration & Cloud Storage: Un Client Orchestrator coordina le chiamate REST multipart tra i servizi e sincronizza i file con Amazon S3 tramite un Bucket Service dedicato.
  • Computer Vision & AI Segmentation: Integrazione di worker Python per rimozione dello sfondo (rembg), segmentazione semantica dei finestrini tramite modello custom YOLOv8 e calcolo dell'inclinazione del veicolo con OpenCV.
  • Dynamic 3D Headless Rendering: Routing condizionale verso due nodi di rendering (Flat vs Inclined) che avviano istanze headless di Blender 4.3 (Cycles GPU/CUDA) per generare ombre, maschere alpha e il render 3D finale.
